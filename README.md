# TARA ISA - Game Development Collection

A collection of 12 games developed using C programming,
TARA ISA and TL-Verilog.

## Beginner Games
1. Snake Game
2. Tic-Tac-Toe
3. Pong Game
4. Catch the Falling Object

## Medium Games
1. Maze Runner
2. Space Shooter
3. Pac-Man Style Game
4. Car Racing Game

## Professional Games
1. Tower Defense
2. Chess
3. Battle Arena
4. Advanced Maze Escape

## Technologies
- C Programming
- TARA ISA
- TL-Verilog
- Game Logic Design
- Algorithm Development

## Objective
To explore game design, software execution and
hardware-oriented implementation through progressive
game development.

## Status
Currently under development.
